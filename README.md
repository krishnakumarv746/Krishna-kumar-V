# Project Name

A simple [To-Do List / Student Management] app built with Java Spring Boot.

## Features
- Add, view, update, delete records
- REST API endpoints
- Connected to MySQL database

## Tech Stack
- Java, Spring Boot
- MySQL
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Set up MySQL database
3. Run `mvn spring-boot:run`
4. Open `http://localhost:8080`
